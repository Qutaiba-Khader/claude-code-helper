Configure Claude Code without reading the docs.

Small browser tools that build real Claude Code configuration — status lines, settings, hooks, skills — and hand you something you can paste straight into Claude. Everything runs in this page: no install, no account, nothing is uploaded.

How it works

Build it visually

Drag the pieces around and watch a live terminal preview update as you go. No guessing what a setting does.

Three ways to apply it

Copy a ready prompt for Claude Code, copy the raw script, or run a one-line installer. Whichever suits you.

Nothing leaves the page

It is a static site. Your layout is kept in your browser and encoded into the share link — never sent anywhere.
