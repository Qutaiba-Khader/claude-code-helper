    Highest first. A key set in a managed file cannot be overridden below it.
    
      
    
    
    
    
    
      
    When changes take effect
    
      
    
        
    
          Live — permissions, hooks,
          apiKeyHelper reload as soon as the file is saved.
        
    
        
    
          Restart — model and outputStyle are read once
          at startup. Everything else: assume a restart.
        
    
        
    
          /status shows what is active, /config edits it,
          /doctor explains why something is not applying.
