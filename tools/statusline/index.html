Status line builder

Arrange the fields, watch the terminal, take the config away.

01 Arrange

Drag into a row, or click to append.

Rows one line each — drag the handle to reorder, drop a field in, or type and press Enter
claude
❯

Colours are standard ANSI — the exact shade comes from your terminal's theme, so this picker shows how the layout lands in each one. Font and size are preview only; a status line cannot change either.

02 Refine optional

Glyphs and links

Turn icons off for plain ASCII if your terminal draws ⎇ or ↻ double-width — Windows Terminal usually does, which also throws the columns out. Clickable links use OSC 8 and need iTerm2, Kitty or WezTerm.

Refresh when

By default the status line redraws on a new message, on /compact, when the permission mode changes and when vim mode toggles. A clock or a countdown will sit still between those, so add a timer if your layout has one.
