Colours are standard ANSI — the exact shade comes from your terminal's theme, so this picker shows how the layout lands in each one. Font and size are preview only; a status line cannot change either.

02 Refine optional

Spacing and dividers

With dividers off, the divider text still sets the gap between fields — it is just drawn as blank space.

Underline rule

Stretching reads $COLUMNS, which Claude Code exports for you (v2.1.153+). tput cols cannot see the terminal from inside the script.

Glyphs and links

Turn icons off for plain ASCII if your terminal draws ⎇ or ↻ double-width — Windows Terminal usually does, which also throws the columns out. Clickable links use OSC 8 and need iTerm2, Kitty or WezTerm.

settings.json options

These go in settings.json, not the script. Padding adds horizontal characters. Refresh re-runs the command every N seconds — leave it at 0 unless you show a clock or a countdown, because updates otherwise only fire on new messages, /compact, permission-mode changes and vim toggles.
