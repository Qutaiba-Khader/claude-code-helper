Status line builder

Drag fields into rows. The preview is what Claude Code will actually draw under your prompt.

Preview

The script emits standard ANSI colour codes — the actual shade is decided by your terminal's scheme, so this picker shows how your layout lands in each one. Font and size are preview only; a status line cannot change either.

Fields

Drag a field into a row, or click it to append to the last row.

Layout

Turn Unicode icons off if your terminal renders ⎇ or ↻ too wide — common in Windows Terminal — and plain ASCII is used instead.
